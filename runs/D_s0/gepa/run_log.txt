### Topology
- Topological space → `(X : Type*) [TopologicalSpace X]`.
- Open / closed sets → `IsOpen s`, `IsClosed s` for `s : Set X`.

- Introduce EVERY hypothesis of the problem as an explicit named argument:

- Formalize the conclusion exactly:
  - "there exists a unique ..." → `∃! x, ...`

- CRITICAL — algebraic structures under a given operation: when the problem says a set with a given operation "is a group" / "is not a group" (or monoid, ring, etc.), the statement must include ALL the axioms of that structure applied to THAT operation.
