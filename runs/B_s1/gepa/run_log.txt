- **Open maps:** "f is an open map" is `IsOpenMap f`. The product projections are `Prod.fst : X × Y → X` and `Prod.snd : X × Y → Y`. To state two claims in one theorem, conjoin them with `∧`.
- **Quantifiers:** `∀ x ∈ s, P x` and `∀ x > 0, P x` are valid.
- **Number theory:** "a is nonzero" is `ha : a ≠ 0`. Parity conditions can be written `a % 2 = 0` (decidable, usable in an `if`) or `Even a` / `Odd a`. `gcd` works on `ℤ`. "√m is not an integer" (for an integer-valued expression m) is `¬ ∃ k : ℤ, k ^ 2 = m`; a variable `n : ℕ` coerces automatically into a `ℤ`-valued expression when the overall type is forced to `ℤ`.
- **Gaussian integers:** the ring ℤ[i] is `GaussianInt`. Do NOT write `ℤ[i]` — that notation is not reliably in scope and gets misparsed as indexing, giving "Unknown identifier `i`" and "failed to prove index is valid". Do NOT write `𝕚` — no such identifier exists (`Complex.I` is only for `ℂ`). The imaginary unit is `GaussianInt.i`. Numerals such as `(2 : GaussianInt)` work.
- **Divisibility:** "a is divisible by b" in a ring/monoid `R` is `(b : R) ∣ (a : R)` (the `∣` notation, typed `\|`), equivalently `∃ q : R, a = b * q`.
- **Group theory:** the order of an element `x : G` (with `[Group G]`) is `orderOf x : ℕ`. "|x| = n" is `hord : orderOf x = n` — there is no `|x|` notation for order, and `x ^ n = 1` is NOT an acceptable substitute (it is weaker). "n is a positive integer" is `hn : 0 < n`.
- **Polynomials:** the type of univariate polynomials over a ring `R` is `Polynomial R`, with notation `R[X]` after `open Polynomial`. The indeterminate is `X : R[X]`. Embed a coefficient `a : R` as the constant polynomial `C a : R[X]`. Write concrete polynomials with these, e.g. `(X ^ 7 + C 15 * X ^ 2 - C 30 * X + C (a : ℚ) : ℚ[X])`.
  - **Coercions into polynomials are NOT automatic across rings:** an integer `a : ℤ` used as a coefficient of a polynomial over `ℚ` must be coerced explicitly: `C (a : ℚ)`. Writing `... + a` with `a : ℤ` inside `ℚ[X]`, or mixing raw numerals without `C`, can fail with typeclass errors such as `failed to synthesize instance ... HSub`/`HAdd`/`HMul`.
  - "p is irreducible in ℚ[X]" is `Irreducible (p : ℚ[X])`.
- **Infinitely many:** "there are infinitely many integers a such that P a" is `Set.Infinite {a : ℤ | P a}` (or `{a : ℤ | P a}.Infinite` with `open Set`). "At most countable" is `Set.Countable` (e.g. `T.Countable` for `T : Set (Set ℝ)`); a union of a set of sets is `⋃₀ T` (`Set.sUnion`, needs `open Set`); open intervals are `Set.Ioo a b` (`Ioo` after `open Set`).

## Lean 4 / Mathlib facts (respect these)
- **Lambdas:** write `fun x => ...` or `fun x ↦ ...`. NEVER write `λ x, ...` or `fun n : ℕ → ℂ, f n` — a comma after the binder is a syntax error ("unexpected token ','; expected '↦', '=>'"). A typed binder is `fun (n : ℕ) => ...` or `fun n : ℕ => ...`; the ascribed type is the type of the bound variable itself.
- **Typeclasses:** `TopologicalSpace`, `MetricSpace`, `NormedField`, etc. are typeclasses, not types. Declare spaces as `(X Y : Type*) [TopologicalSpace X] [TopologicalSpace Y]`. Writing `(X Y : TopologicalSpace)` fails with "type expected, got (TopologicalSpace : Type _ → Type _)".
- **Sets vs. indexed families:** if `s : Set X` and `x : X`, then `s x` is the PROPOSITION `x ∈ s`, not a set. A family "T_α" must be declared with an index type and a function, e.g. `(ι : Type*) (T : ι → Set (Set X))`; then `T α : Set (Set X)` and its union is `⋃ α, T α` (`Set.iUnion`, needs `open Set`). Declaring `(T : Set (Set X))` and then writing `T α` fails with "Application type mismatch ... has type Prop ... but is expected to have type Set (Set X)".
- **Big unions/intersections vs. binary ones:** `⋃ i, U i` and `⋂ i, C i` (with a binder) are `Set.iUnion` / `Set.iInter`. The symbols `∪` and `∩` are BINARY infix operators only — writing `∩ i, C i` is a syntax error ("unexpected token '∩'; expected ..."). "The intersection is nonempty" is `(⋂ i, C i).Nonempty` or `(⋂ i, C i) ≠ ∅`; "each C i is nonempty" is `∀ i, (C i).Nonempty` or `∀ i, C i ≠ ∅`.
- **Chaining conditions on a quantified family:** prefer nested implications over one long `∧`-chain mixed with `→`, because `∀` and `→` extend as far right as possible, so `A ∧ B ∧ ∀ i j, i ≤ j → P i j → Q` puts `Q` INSIDE the `∀` — rarely what you intend. Write e.g. `∀ (C : ℕ → Set X), (∀ i, IsClosed (C i)) → (∀ i, (C i).Nonempty) → (∀ i j, i ≤ j → C j ⊆ C i) → (⋂ i, C i).Nonempty`.
- **Interval sets:** `Set.Ici a` is [a, ∞), `Set.Ioi a` is (a, ∞), `Set.Iic a` is (-∞, a], `Set.Iio a` is (-∞, a), `Set.Icc a b` is [a, b], `Set.Ioo a b` is (a, b). Beware: `Set.Icc 0 0 = {0}`.

## Lean 4 / Mathlib facts (respect these)
- **Lambdas:** write `fun x => ...` or `fun x ↦ ...`. NEVER write `λ x, ...` or `fun n : ℕ → ℂ, f n` — a comma after the binder is a syntax error ("unexpected token ','; expected '↦', '=>'"). A typed binder is `fun (n : ℕ) => ...` or `fun n : ℕ => ...`; the ascribed type is the type of the bound variable itself.
- **Typeclasses:** `TopologicalSpace`, `MetricSpace`, `NormedField`, `Group`, etc. are typeclasses, not types. Declare spaces as `(X Y : Type*) [TopologicalSpace X] [TopologicalSpace Y]` and groups as `(G : Type*) [Group G]`. Writing `(X Y : TopologicalSpace)` fails with "type expected, got (TopologicalSpace : Type _ → Type _)".
- **Sets vs. indexed families:** if `s : Set X` and `x : X`, then `s x` is the PROPOSITION `x ∈ s`, not a set. A family "T_α" must be declared with an index type and a function, e.g. `(ι : Type*) (T : ι → Set (Set X))`; then `T α : Set (Set X)` and its union is `⋃ α, T α` (`Set.iUnion`, needs `open Set`). Declaring `(T : Set (Set X))` and then writing `T α` fails with "Application type mismatch ... has type Prop ... but is expected to have type Set (Set X)".
- **Derivative:** the derivative of `f : ℝ → ℝ` as a function is `deriv f`. There is no `f'` notation in Mathlib. "f'(x) → L as x → +∞" is `Tendsto (deriv f) atTop (nhds L)`.
- **Differentiability:** `DifferentiableAt ℝ f x`, `DifferentiableOn ℝ f s`, `Differentiable ℝ f`. "f is holomorphic on an open set Ω" is `DifferentiableOn ℂ f Ω` (plus `hΩ : IsOpen Ω` when given).
- **Limits:** "g(x) → L as x → +∞" is `Tendsto (fun x => g x) atTop (nhds L)` (needs `open Filter` and `open Topology` for `Tendsto`/`atTop`/`nhds`).
- **Series:** "the series ∑ aₙ converges" is `Summable (fun n => a n)`; "∑ aₙ = L" is `HasSum (fun n => a n) L`; a partial sum is `∑ k in Finset.range n, a k`. Do NOT confuse "the series converges" with "the terms tend to 0" — never render series convergence as `Tendsto (fun n => a n) atTop (nhds 0)`.
- **Complex parts:** real/imaginary parts are `Complex.re` and `Complex.im`, or `re`/`im` after `open Complex`, or dot notation `(f z).im`. There is no `Im` or `Re` identifier.
- **Unit circle:** there is no `Set.unitCircle`. "z lies on the unit circle" is `‖z‖ = 1` or `z ∈ Metric.sphere (0 : ℂ) 1`.
- **No `ConstantOn`:** Mathlib has no `ConstantOn` predicate. Use `∃ c, ∀ z ∈ s, f z = c` (or `Set.EqOn f (fun _ => c) s`).
- **Open maps:** "f is an open map" is `IsOpenMap f`. The product projections are `Prod.fst : X × Y → X` and `Prod.snd : X × Y → Y`. To state two claims in one theorem, conjoin them with `∧`.
- **Quantifiers:** `∀ x ∈ s, P x` and `∀ x > 0, P x` are valid.
- **Number theory:** "a is nonzero" is `ha : a ≠ 0`. Parity conditions can be written `a % 2 = 0` (decidable, usable in an `if`) or `Even a` / `Odd a`. `gcd` works on `ℤ`.
- **Group theory:** the order of an element `x : G` (with `[Group G]`) is `orderOf x : ℕ`. "|x| = n" is `hord : orderOf x = n` — there is no `|x|` notation for order, and `x ^ n = 1` is NOT an acceptable substitute (it is weaker). "n is a positive integer" is `hn : 0 < n`.

Writing `... + a` with `a : ℤ` inside `ℚ[X]`, or mixing raw numerals without `C`, can fail with typeclass errors such as `failed to synthesize instance ... HSub`/`HAdd`/`HMul`.
  - "p is irreducible in ℚ[X]" is `Irreducible (p : ℚ[X])`.

In numeric equations and exponents ALWAYS use `q.natDegree` (e.g. `Nat.card ... = p ^ q.natDegree`); `WithBot ℕ` cannot be an exponent (no `HPow ℕ (WithBot ℕ)` instance — this is a synthInstanceFailed error). - **Quotient rings:** "R/I" is `R ⧸ I` with `I : Ideal R` (the type is `Ideal.Quotient I`). There is NO `Polynomial.quotientRing`. - **Connectedness and interior:** "S is connected" is `IsConnected S` (or `IsPreconnected S` when nonemptiness is not intended); the interior is `interior S` (lowercase). There is NO `Connected` or `Interior` identifier. `IsConnected`, `IsPreconnected` and `interior` are in the root namespace, so they work under the usual opens.
- **Infinitely many:** "there are infinitely many integers a such that P a" is `Set.Infinite {a : ℤ | P a}` (or `{a : ℤ | P a}.Infinite` with `open Set`). ## Lean 4 / Mathlib facts (respect these)
- **Lambdas:** write `fun x => ...` or `fun x ↦ ...`. NEVER write `λ x, ...` or `fun n : ℕ → ℂ, f n` — a comma after the binder is a syntax error ("unexpected token ','; expected '↦', '=>'"). - **Typeclasses:** `TopologicalSpace`, `MetricSpace`, `NormedField`, `Group`, `Field`, `Module`, `Fintype`, `Infinite`, etc. are typeclasses, not types. Declare spaces as `(X Y : Type*) [TopologicalSpace X] [TopologicalSpace Y]`, a group as `(G : Type*) [Group G]`, a vector space as `(F : Type*) [Field F] (V : Type*) [AddCommGroup V] [Module F V]`. Writing `(X Y : TopologicalSpace)` fails with "type expected, got (TopologicalSpace : Type _ → Type _)".
- **Cauchy sequences vs Cauchy filters:** for a sequence `u : ℕ → X` (with `[MetricSpace X]` or `[UniformSpace X]`), "u is a Cauchy sequence" is `CauchySeq u`. `Cauchy` takes a `Filter X`, NOT a sequence: `Cauchy (fun n => ...)` fails with "Application type mismatch ... has type ℕ → Y but is expected to have type Filter". - **Finite sums and products:** use big-operator notation `∑ i in s, f i` / `∏ i in s, f i` (needs `open scoped BigOperators`), or `Finset.sum s f` / `Finset.prod s f` — the finset is the FIRST argument, the function the SECOND. Write `Finset.range n` fully qualified when `Finset` is not opened.
- **Inverse of a product reverses order:** for `a : ℕ → G` with `[Group G]`, state it as `(∏ i in Finset.range n, a i)⁻¹ = ∏ i in Finset.range n, (a (n - 1 - i))⁻¹`. (Natural subtraction `n - 1 - i` is fine for `i < n`.) Do NOT write the RHS as `∏ i in Finset.range n, (a i)⁻¹`.
- **"Finitely many" objects:** use `s : Finset α` (then `∀ x ∈ s, P x`, `⋃ x ∈ s, ...`, `∑ x in s, ...`) or an indexed family `(ι : Type*) [Fintype ι] (f : ι → α)`. - **Submodules / subspaces:** a subspace of an `F`-module `V` is `W : Submodule F V`. "W is a proper subspace" is `W ≠ ⊤` (or `W < ⊤`); there is NO `IsProperSubspace` identifier. The whole space as a set is `Set.univ : Set V` — a type `V` is not a `Set V`, so never write `... = V` for a set equality. Coerce a submodule to a set with `(W : Set V)` (or `↑W`) for unions/intersections; `x ∈ W` works directly.
- **Infinite vs nontrivial:** "the field F is infinite" is the typeclass `[Infinite F]`. `Nontrivial F` only means F has at least two elements — it does NOT imply infinite. Do not substitute one for the other.
- **Sets vs. indexed families:** if `s : Set X` and `x : X`, then `s x` is the PROPOSITION `x ∈ s`, not a set.
