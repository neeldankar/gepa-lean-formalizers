Lean notation

  
∀ x, P x for every x, P x holds

  
∃ x, P x there is some x with P x

  
∃! x, P x there is exactly one such x

  
P → Q if P then Q (also a function type)

  
P ↔ Q P if and only if Q

  
¬ P not P; a ≠ b means ¬ (a = b)

  
P ∧ Q, P ∨ Q and, or

  
ℕ ℤ ℚ ℝ ℂ naturals (from 0), integers, rationals, reals, complex numbers

  
(n : ℤ) or ↑n the coercion: n viewed in a bigger type

  
(2 : ℝ) a type ascription: this 2 is a real number

  
Set α a set of elements of type α; x ∈ s, s ⊆ t

  
Finset α a finite set; Finset.range n is {0, ..., n-1}

  
s.card or Finset.card s the number of elements of a finite set

  
∑ i ∈ s, f i, ∏ i ∈ s, f i sum and product over a finite set

  
Function.Injective f one-to-one; Function.Surjective f onto

  
Filter.Tendsto f l₁ l₂ f tends to l₂ along l₁ (limits)

  
atTop the filter "n goes to infinity"

  
𝓝 a the neighbourhoods of a, as in "x tends to a"

  
a ≡ b [ZMOD n] a is congruent to b modulo n (integers)

  
Polynomial R or R[X] polynomials over R; X the variable

  
p.degree, p.roots, Polynomial.derivative p degree, roots, derivative

  
[Group G], [Field K] square brackets: G is assumed to carry this structure

  
{x : ℝ} curly braces: an implicit argument Lean fills in

  
theorem t (x : ℝ) (h : 0 < x) : P x everything before the last colon is given (variables and hypotheses h); after it is what is claimed

  
(h₁ : a) (h₂ : b) : c reads "if a and b, then c"

  
:= by sorry the proof is left out; only the statement matters here
