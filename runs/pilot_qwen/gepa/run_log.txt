## Mathlib cheat sheet (distilled from previous compile failures)
- **Span**: the span of a set of vectors is `Submodule.span R s` (lowercase `span`); `Span` (capital S) does not exist. With `open Submodule` you may write `span R s`. "s spans V" is `Submodule.span R s = ⊤`.
- **Linear independence**: `LinearIndependent R v` takes a *function* `v : ι → M`, not a set. For `S : Set M` write `LinearIndependent R ((↑) : S → M)`. Passing `S` directly makes Lean read `Set M` as `M → Prop` and fails with "failed to synthesize `AddCommMonoid Prop`".
- **Constrained existentials**: `∃ r : ℝ ≥ 0, ...` is invalid — Lean parses `ℝ ≥ 0` as a type and fails with "failed to synthesize `LE Type`" / "OfNat Type 0". Write `∃ r : ℝ, 0 ≤ r ∧ ...` (or the binder-predicate form `∃ r ≥ 0, ...`), or use `ℝ≥0` (NNReal).
- **Complex absolute value**: `|w|` does not work on `ℂ` (fails with "failed to synthesize `Lattice ℂ`"). Use the norm `‖w‖` or `Complex.abs w` (both return a real).
- **Mixed real–complex multiplication**: with `r : ℝ` and `w : ℂ`, write `(r : ℂ) * w` (coercion) or `r • w` (the `SMul ℝ ℂ` instance). Plain `r * w` does not type-check.
- **Submodules**: the ambient module as a submodule of itself is `⊤`, not `V`. "W is a proper subspace" is `W ≠ ⊤` (or `W < ⊤`). There is no `⊂`/`HasSSubset` instance on submodules — never write `W ⊂ V`. Coerce a submodule to a set with `(W : Set V)` when a set is needed.
- **Finite families**: "finitely many X_i" is a function `X : Fin n → ...` with `(n : ℕ)` — not a single object plus a loose index `i : Fin n`. Their union as sets is `⋃ i, (X i : Set V)`; "V equals their union" is `⋃ i, (X i : Set V) = Set.univ` (or, as submodules, `⨆ i, X i = ⊤`).
- **Countability/finiteness**: `S.Countable` / `Set.Countable S`, `S.Finite` / `Set.Finite S`, and the typeclass `Countable α`. Note `Set.Countable` already includes finite sets, so "finite or countably infinite" can be just `S.Countable` (or `S.Finite ∨ S.Countable` to mirror the wording).
- **Sets**: the whole carrier set is `Set.univ`; indexed unions are `⋃ i, s i` (`Set.iUnion`).
