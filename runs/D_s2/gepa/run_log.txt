# Verified concept mappings

## Topology
- "X is a topological space / compact / Hausdorff" → `(X : Type*) [TopologicalSpace X] [CompactSpace X] [T2Space X]`
- "a subset / subspace A of a topological space X" → `A : Set X`. The subtype `↥A` automatically carries the subspace topology, so `[MetrizableSpace A]`, `IsClosed A`, `IsOpen A`, `IsCompact A` apply directly.
- ⚠️ NEVER use `Subspace X` for a topological subspace. In Mathlib, `Subspace` is a LINEAR ALGEBRA concept: `Subspace K M` requires `[DivisionRing K] [AddCommGroup M] [Module K M]`. On a general topological space it fails with "type expected, got Subspace X ...".
- "A is closed / open" → `IsClosed A` / `IsOpen A`
- "X is the union of X₁ and X₂" → `X₁ ∪ X₂ = Set.univ`
- "X is metrizable" → `MetrizableSpace X` (a Prop-valued typeclass: there EXISTS a compatible metric). Do NOT use `MetricSpace X` (that equips X with one chosen metric — a different, stronger object), and do not invent a `Metrizable` predicate — it does not exist.
- "f : X → Y is an open map" → `∀ U : Set X, IsOpen U → IsOpen (Set.image f U)` (judged faithful). The named predicate `IsOpenMap f` exists in Mathlib — use it only if you are certain of its name and signature.
- Projections π₁ : X × Y → X and π₂ : X × Y → Y → `Prod.fst` / `Prod.snd`, or pattern lambdas `fun (x, y) => x`. The product topology instance on `X × Y` is automatic.

## Group theory
- "G is a finite group of order n" → `(G : Type*) [Group G] [Fintype G] (h : Fintype.card G = n)`
- "P is a Sylow p-subgroup of G" → `(P : Sylow p G)` with `p : ℕ` (e.g. `Sylow 3 G`)
- "P (a Sylow subgroup or subgroup) is normal" → `P.Normal`
- "G is abelian" → `∀ g h : G, g * h = h * g` (judged faithful)

## Number theory / algebra
- ℤ/nℤ (residue classes) → `ZMod n`
- gcd of two integers → `Int.gcd x y`
- "a is odd / even" → `Odd a` / `Even a`

## Linear & functional analysis
- "z is an eigenvalue of a linear map T" → `Module.End.HasEigenvalue T z` — do NOT use `z ∈ spectrum ℂ T`; the spectrum is a different concept from the set of eigenvalues, and this substitution was judged unfaithful even though they coincide in finite dimensions.
- "a complex number z is real" → state realness directly, e.g. `∃ r : ℝ, z = r` — do NOT replace it with a different condition such as `z.im = 0`.
- "T is a normal operator" → `T.adjoint ∘ₗ T = T ∘ₗ T.adjoint`
