- Example: `1 + 1/2 + ... + 1/(p-1)` → `∑ i ∈ Finset.Icc 1 (p - 1), (1 : ℚ) / (i : ℚ)` (equivalently `∑ i ∈ Finset.range (p - 1), (1 : ℚ) / ((i : ℚ) + 1)`).

### Coercions: both sides of every `=`, `↔`, `∣` must have the same type
- Divisibility: `∣` (typed `\|`). "p ∣ a" with `p : ℕ` and `a : ℤ` → `(p : ℤ) ∣ a`.
- An integer fraction equal to a rational number: coerce, e.g. `(a : ℚ) / (b : ℚ)`.
- When a `ℕ`-typed variable appears inside a `ℚ`/`ℝ` expression, write the cast explicitly, e.g. `(i : ℚ)`.
- e.g. `Complex.re l` is a real; compare it with a real or coerce appropriately.

### Use only identifiers that exist in Mathlib — verified vocabulary
Do not invent plausible-sounding `IsX` names; several natural guesses do NOT exist. The following are verified to exist (with `import Mathlib`):

Topology:
- Open/closed sets: `IsOpen s`, `IsClosed s` for `s : Set X`.
- Open map: `IsOpenMap f` (it means `∀ U : Set X, IsOpen U → IsOpen (f '' U)`).
- Compactness: `IsCompact s` for a set; `CompactSpace X` (a class) for the whole space.
- Hausdorff: `T2Space X` (a class).
- Metrizable: `MetrizableSpace X` (a Prop on a type with a `TopologicalSpace` instance). There is NO `IsMetrizable`.
- The whole space as a set: `Set.univ`. "X = X₁ ∪ X₂" with `X₁ X₂ : Set X` → `Set.univ = X₁ ∪ X₂`.
- Subspaces: a set `s : Set X` coerces to a type equipped with the subspace topology, so `MetrizableSpace s`, `CompactSpace s`, `T2Space s` typecheck directly.
- Projections: `Prod.fst : X × Y → X`, `Prod.snd : X × Y → Y`. Image of a set: `f '' U`.

Group theory:
- Subgroup inclusion: `H ≤ K` for `H K : Subgroup G`. "Let H ≤ K ≤ G" → `(H K : Subgroup G) (hHK : H ≤ K)`.
- Index of a subgroup in the ambient group: `H.index : ℕ` is |G : H| for `H : Subgroup G` (the ambient `G` is implicit in `H`'s type — using `H.index` is how `G` enters the formula). It needs no finiteness hypothesis (it is `0` when infinite).
- Relative index: `H.relIndex K : ℕ` is |K : H| — the smaller subgroup is the receiver, the larger one the argument. If the context defines a wrapper such as `Subgroup.relindex H K := H.relIndex K`, call the wrapper: `Subgroup.relindex H K`.
- Index multiplicativity: |G:H| = |G:K| · |K:H| for `H ≤ K` is `H.index = K.index * H.relIndex K`. When the problem says "do not assume G is finite", do NOT add `[Fintype G]`.
- Conjugacy: "x and y are conjugate in G" → `∃ g : G, g * x * g⁻¹ = y` (equivalently `IsConj x y`). The conjugated object is the WHOLE element: "ab and ba are conjugate" → `∃ g : G, g * (a * b) * g⁻¹ = b * a`. Parenthesize `a * b` as a single element; do NOT conjugate the factors separately — `∃ g : G, g * a * g⁻¹ = b * a * b⁻¹` is a different, wrong statement.
- Sylow p-subgroup: the TYPE `Sylow p G` (requires `[Group G] [Fintype G]`; the prime `p : ℕ` is the first argument). Write `(P : Sylow 3 G)`. There is NO `IsSylowSubgroup` predicate.
- A `P : Sylow p G` coerces to `Subgroup G` (parent projection `P.toSubgroup`); e.g. normality of a Sylow subgroup: `(hP : (P : Subgroup G).Normal)` or equivalently `(hP : P.toSubgroup.Normal)`.
- Normal subgroup: `H.Normal` (i.e. `Subgroup.Normal H`, a class) for `H : Subgroup G`. There is NO `IsNormal`.
- "G is abelian" as a Prop: `∀ a b : G, a * b = b * a`. There is NO `IsAbelian`. Do not use `CommGroup G` as a conclusion — it is a class, and the group structure on `G` is already fixed.
- Order of a finite group: `Fintype.card G = n` together with `[Fintype G]`.

Number theory:
- Primality: `Nat.Prime p` for `p : ℕ`. "p is an odd prime" → `(hp : Nat.Prime p) (hpodd : Odd p)` (equivalently `(hpodd : p ≠ 2)`).
- gcd: `Int.gcd` / `gcd`; modular arithmetic: `ZMod n`; "admits no group structure": `IsEmpty (Group (ZMod n))` (there is no `IsGroup` predicate).

Other standard notions:
- Operators: `Module.End ℂ V` or `V →ₗ[ℂ] V`; adjoints `LinearMap.adjoint`; self-adjointness `IsSelfAdjoint`; eigenvalues `Module.End.HasEigenvalue` / `Module.End.eigenvalues`.
- `InnerProductSpace ℂ V` is a typeclass assumption `[InnerProductSpace ℂ V]` on a space `V`, not a type to quantify over.

### If you are unsure whether a named predicate exists, unfold the definition from primitives
This always compiles and stays faithful:
- abelian group → `∀ a b : G, a * b = b * a`
- open map → `∀ U : Set X, IsOpen U → IsOpen (f '' U)`
- normal subgroup → `∀ g h : G, h ∈ H → g * h * g⁻¹ ∈ H`
- conjugate → `∃ g : G, g * x * g⁻¹ = y`
